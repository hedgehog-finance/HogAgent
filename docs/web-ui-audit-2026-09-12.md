# WebUI 审计与回归记录（2026-09-12）

## 范围与版本

本次核对 Codex 风格布局重构后的现有 WebUI 功能、展示和交互，并补充版本显示。沿用 `package.json` 中的 `1.2.3`，WebUI 构建和 CLI 通过 `src/version.ts` 读取同一来源。构建时将实际版本写入静态 HTML；没有新增或修改 API 路由、WS action 和消息字段，也没有修改 vendor 源码。

## 发现与修复

| 场景 | 修复 |
| --- | --- |
| 断线或新会话切换期间再次点击新会话 | 禁用入口并阻止重复请求，等待原有 `ready` 流程完成 |
| 发送斜杠命令后再次按 Enter | 清除残留的命令建议，防止空输入被旧建议重新填入 |
| 技能菜单打开时切换模式或页面 | 同步关闭输入区菜单 |
| 收到 `ready` 或思考深度变更事件 | 刷新输入区模型与思考深度显示 |
| 只有审计模型产生 Token 用量 | 显示审计统计，不再误判为无数据 |
| LLM 设置保存失败 | 收到成功回执后才更新当前配置显示；等待期间阻止重复保存，失败或断线后允许重试 |
| MCP 服务在 HTTP / stdio 间切换 | 先读取当前已渲染的字段，再替换传输类型，避免读取不存在的输入框 |
| 侧栏技能卡片与输入区技能菜单共用类名 | 将菜单样式限定在菜单容器内，避免卡片布局被覆盖 |
| 旧 WebUI 进程读取新版 HTML 后显示版本占位符 | 改为构建时写入实际版本，移除服务端版本替换；构建同步、静态文件断言及检查命令防止版本遗漏 |
| 输入框模型控制需打开完整模态框 | 改为旁侧选择模型、滑动思考深度并应用；列表仅取当前已生效提供商，无列表锁定 `auto`；保留完整设置入口 |

## 复现浏览器检查

在 `hogagent/` 下运行：

```bash
node test/browser/webui-smoke.mjs
```

默认使用 Playwright 已安装的 Chromium。也可指定本机浏览器，例如 macOS：

```bash
HOGAGENT_BROWSER_EXECUTABLE='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
  node test/browser/webui-smoke.mjs
```

脚本输出检查结果和临时截图目录，所有 HTTP 与 WS 流量均使用内存测试数据，不会修改实际用户配置。
