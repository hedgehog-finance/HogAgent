# 多模态输入（1.2.6）

## 附件用途与协议

WebUI 的「上传文件」允许任意文件，仅产生工作区文件引用。即使扩展名是 PNG、MP4，也不会自动读取其内容加入模型请求。「添加图片／视频」及剪贴板实际提供的媒体创建显式 `kind: image | video`。缺省 `kind` 和 `kind: file` 均保持普通文件语义。用户可将媒体显式改为普通文件。

现有 `prompt`、`steer`、`follow_up` 命令增加可选 `attachments` 数组：

```json
{"type":"prompt","text":"说明图片","attachments":[{"kind":"image","path":"files/example.png","name":"example.png","mimeType":"image/png","size":1024}]}
```

每项保留路径、名称、大小、MIME 和可选项目 ID；服务端接收后记录 `sha256`，重放时拒绝已变更内容。普通文件不经过媒体读取器。仅媒体消息使用默认的分析提示。上传仍走已有接口，项目路径只在运行时绑定的项目根目录下解析。

媒体限 JPEG／PNG／WebP（单文件 5,000,000 字节）、MP4／MOV（单文件 7,000,000 字节），每消息最多 10 项，累计 Base64 上限 15 MiB；原上传路径或供应商更小的限制仍生效。视频原生发送，不抽帧、不转码、不上传外部临时存储。浏览器播放失败仅表示无法预览，不会自动转换附件用途。

## 模型能力

Hedgehog 模型列表从同一配置基址的 `/models` 和 `/model/info` 获取。只读取 `model_name`、`model_info.supports_vision`、`supports_video_input`；同名多部署取交集，缺失能力不启用。模型配置使用 `inputModalities: ["text", "image", "video"]`，图片映射至已有 `model.input` 通道；视频仅对 `openai-completions` 开启。状态 `capabilities.media` 和模型／设置变更事件返回当前能力，以及 `limits`（原始字节上限）和 `mimeTypes`（本次支持的格式）。自定义服务须明确提供能力，不能凭模型名称推断。

原生视频使用阿里云 [视觉理解协议](https://help.aliyun.com/zh/model-studio/vision) 的 `video_url.url = data:video/mp4;base64,...` 内容块。供应商仍负责校验时长、尺寸等约束。LiteLLM 首批显式配置 Qwen3.8-Max、Qwen3.8-Flash、Qwen3.7-Plus、Qwen3.7-Flash；其他模型默认关闭媒体能力。

## 消息、审核和恢复

会话持久化 `hogagent.media.v1` 自定义消息，保存引用、摘要、记录 ID、原始输入文本和轮次关联，不保存媒体 Base64。主 Harness 开始实际用户轮次时追加同 ID 的绑定事实，重放取最新版本；队列媒体按唯一标记注入对应用户内容，即使引用记录延迟写入也不改变轮次。进入主模型前失败的输入保留历史展示，后续无关请求不隐式重发；当前请求的分类审核及显式重试仍可读取媒体。仅最后一条尚未绑定、文本和冻结引用完全相同的立即重试复用记录 ID。

项目层 context/payload 钩子在请求时读取真实文件并展开媒体，不改动 `src/vendor/`。活动作用域按 Harness 隔离；队列媒体只有匹配的用户消息被消费后才注入。审核和压缩后的请求、历史恢复继续保留已消费媒体及其原始输入；未消费队列不提前显示或发送。累计媒体或最终媒体请求体超过 15 MiB 时报错，需减少附件或开始新会话。切到不支持历史媒体的模型也会拒绝请求，不静默丢弃历史附件。

长任务的主模型及需要原始输入的审核模型都必须支持对应媒体。审核、评分及后续迭代共享本轮媒体作用域，禁止静默替换模型。缺文件、路径越界、摘要变化、未知能力均报错；WebUI 保留失败输入供重试。历史预览复用鉴权 `/api/download`，只允许该会话已有媒体引用。

## Windows 与验证

媒体通过 Node 路径 API、真实路径及上传目录边界校验读取，不使用 shell 拼接路径。Cmd+V／Ctrl+V 使用浏览器 `paste` 事件，只处理实际 File 数据；剪贴板仅有路径字符串时保留文本。混合文本和文件各保留一次。

自动化覆盖入口用途、编码、摘要、越界、延迟队列关联、失败重试、压缩后的历史归属、最终请求体上限及模型拒绝；浏览器合成粘贴不等于操作系统剪贴板验收。Windows 11 Chrome／Edge、macOS Chrome／Safari 的真实文件选择、截图粘贴、视频播放和恢复仍须分别实机验收。
